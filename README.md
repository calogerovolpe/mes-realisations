# Mes réalisations

Portfolio statique présentant des travaux personnels d'analyse et de
modélisation : business plans, modèles financiers Excel, identité visuelle.

Site publié via GitHub Pages : `https://<compte>.github.io/mes-realisations/`

## Technique
HTML5 + CSS, aucun framework, aucun build, aucune dépendance externe.

## Structure
- Pages HTML à plat à la racine
- `assets/css/style.css` — feuille de style unique
- `assets/img/` — captures d'écran et planches
- `.clinerules/` — règles de travail
- `memory-bank/` — état d'avancement du projet

## Contenu
Exercices d'analyse et de modélisation réalisés à titre personnel.
Noms commerciaux inventés ; études menées sur des marchés, emplacements et
concurrents réels. Données issues de sources publiques et de catalogues
fournisseurs.
