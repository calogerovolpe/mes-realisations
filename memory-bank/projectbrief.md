# projectbrief.md

Nom : Mes réalisations
Nature : site portfolio statique, public, sans base de données.
Technique : HTML/CSS pur, aucun framework, aucun build, GitHub Pages.
Dépôt : mes-realisations (public), branche main, dossier / (root).

Objectif
Prouver par la preuve — méthode, captures d'écran, extraits rédigés — des
compétences en gestion administrative, étude de marché, modélisation financière
et identité visuelle.

Critère de réussite
Un recruteur comprend en 30 secondes ce que le propriétaire sait faire, et
aucun nom de personne réelle n'est exposé.

Hors périmètre
Blog, téléchargement de fichiers sources, version néerlandaise, comptes
utilisateurs, paiement, newsletter.

Nature des contenus
Exercices personnels. Aucun projet n'existe ni n'a existé. Les noms commerciaux
sont inventés ; les études portent sur des marchés, emplacements et concurrents
réels, avec des données sourcées.
