# projectbrief.md

Nom affiché : Volpe Calogero
Titre du site : Volpe Calogero — Mes réalisations administratifs
Nature : portfolio statique, public, interactif et imprimable, sans base de données.
Technique : HTML5, CSS, JavaScript vanilla en amélioration progressive ;
aucun framework, aucun build, GitHub Pages.
Dépôt : mes-realisations (public). Développement de la refonte sur la branche
« refonte » ; publication sur la branche main, dossier / (root).

Objectif
Prouver par la preuve — méthode, captures d'écran, extraits rédigés — des
compétences en gestion administrative, suivi budgétaire et reporting,
modélisation Excel et rédaction, auprès de recruteurs de postes administratifs.

Règle de décision
« Est-ce que ça aide un recruteur, ou est-ce que ça m'amuse ? »
Si la réponse est « m'amuse », la fonctionnalité n'est pas codée.

Critère de réussite
Un recruteur comprend en 30 secondes ce que le propriétaire sait faire ; un
recruteur qui ne consulte pas le site peut quand même conserver le dossier
(impression / export PDF).

Hors périmètre
Réorientation vers le dessin technique ou le développement web ; blog ;
téléchargement de fichiers sources ; version néerlandaise ; comptes utilisateurs ;
paiement ; newsletter ; framework, CDN, étape de build.

Nature des contenus
Exercices personnels. Aucun projet n'existe ni n'a existé. Les noms commerciaux
sont inventés ; les études portent sur des marchés, emplacements et concurrents
réels, avec des données sourcées.
